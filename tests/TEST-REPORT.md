## 已知边界

普通网页无法可靠接管操作系统级 Alt+Tab、Command+Tab、系统安全键、强制退出，以及浏览器自身保留的快捷键。支持 Keyboard Lock 的浏览器在全屏和用户手势满足时可以进一步锁定键盘；当前验收环境未提供该 API，因此页面显示降级提示，但常见快捷键拦截仍然有效。

`KeyboardEvent.code` 识别物理键位，不等同于输入字符。Fn 键、厂商自定义宏键和未被浏览器暴露的多媒体键，仍受操作系统和浏览器事件模型限制。
